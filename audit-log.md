# Data Quality Audit Log

22 findings recorded while auditing NHS acute provider performance data across 134 trusts. Entries are listed in the order they were found, so early findings are sometimes corrected by later ones. AQ-001 refers to 144 rows, for example, which AQ-017 later corrects to 134 once the metadata rows were identified.

Severity is shown as **H** (high), **M** (medium) or **L** (low).

| ID | Scope | Finding | Action |
|---|---|---|---|
| AQ-001 | All metrics, all trusts | **M** Dataset contains 144 rows but the interactive NHS source table displayed only 118 to 119 trusts. Difference likely due to inclusion of specialist and children's trusts filtered out of the web view. Requires confirmation. | Noted, no rows removed pending investigation (See AQ-017) |
| AQ-002 | All metric columns, all trusts | **H** Data covers two different time periods: elective and cancer metrics are January 2026, A&E metrics are February 2026. Time period inconsistency across columns affects direct comparison. | Flagged, noted in all analysis as a limitation |
| AQ-003 | A&E 12-hour performance, all trusts | **H** Column is marked "Provisional" in the source file. Figures may be subject to revision and should not be treated as final. | Flagged as provisional in analysis |
| AQ-004 | Cancer Faster Diagnosis, Alder Hey | **M** Trust records 100% for Cancer Faster Diagnosis Standard, a statistical outlier. May reflect small patient volume at a specialist children's hospital rather than a data error. Requires investigation. | Flagged for investigation in analysis phase |
| AQ-005 | Region, all trusts | **M** Regional classification was not available in source files or reference files. The etr.csv reference file contained town-level geography rather than NHS England regional groupings. Region data was manually assigned using secondary knowledge. | Resolved, manual region mapping applied and verified |
| AQ-006 | Metric counts, multiple trusts | **H** Provider counts differ across metrics. Some columns show "Rank out of 118" while others show "Rank out of 119." Indicates at least one trust has missing data for certain metrics. | Under investigation, blanks check in progress (See AQ-012 and AQ-017) |
| AQ-007 | All percentage columns, all trusts | **L** Percentage sense check completed across all 144 rows and 7 metric columns. No values found outside the 0 to 100% range. Data passes basic boundary validation. | Closed, no action required |
| AQ-008 | Multiple metrics, 9 trusts | **M** Nine trusts have 2 missing metric values each. Pattern suggests specialist trusts not operating standard cancer or A&E pathways. Full list to be documented. | Under investigation (See AQ-012)|
| AQ-009 | Single metric, 4 trusts | **L** Four trusts each have 1 missing metric value. To be investigated whether the same metric is absent across all four or different metrics per trust. | Under investigation (See AQ-012)|
| AQ-010 | Multiple metrics, Great Ormond Street | **M** Three missing metric values. Trust is a specialist paediatric hospital and does not operate standard acute pathways for cancer and emergency care. Missing data is consistent with trust type rather than a reporting failure. | Flagged, recommend excluding from cross-trust comparisons or treating separately |
| AQ-011 | A&E 4-hour and 12-hour, 10 to 11 trusts | **H** A&E metrics have the highest missing data rate in the dataset, significantly higher than elective and cancer metrics. Likely reflects specialist trusts without conventional A&E departments rather than reporting failures. This structural difference means A&E metrics are not comparable across all trusts and should be analysed as a subset. | Flagged, A&E analysis scoped to reporting trusts only |
| AQ-012 | All metrics, 14 trusts | **M** 25 blank cells replaced with N/R (Not Reported) to distinguish intentional non-reporting from accidental data gaps. Concentrated in A&E metrics (21 of 25 blanks) consistent with specialist trust profiles. | Resolved, N/R applied |
| AQ-013 | New column, all trusts | **L** Trust Type column added to distinguish General Acute from Specialist trusts. 12 Specialist trusts identified as likely source of N/R values in cancer and A&E metrics. Separating trust types ensures like-for-like comparison in analysis. | Resolved, Trust Type column populated |
| AQ-014 | Below Average Count, 3 trusts | **H** Three General Acute trusts (Great Western, Liverpool University, North Bristol) scored 6 out of 7, below average on 6 metrics. Identified as consistent underperformers across the dataset. | Flagged, included in analysis findings |
| AQ-015 | Below Average Count, all trusts | **M** A further 18 General Acute trusts scored 5 out of 7, suggesting underperformance is not isolated to a small number of outliers but reflects a broader systemic pattern. | Flagged, included in analysis findings |
| AQ-016 | Regional analysis, all regions | **M** Initial regional averages were distorted by inclusion of Specialist trusts in AVERAGEIF calculations. AVERAGEIFS and COUNTIFS formulas implemented to exclude Specialist trusts from regional comparison. | Resolved, formulas updated |
| AQ-017 | Dataset row count, all trusts | **M** Initial count of 144 rows was incorrect. Raw file contains 10 rows of metadata before trust data begins at row C11. Confirmed trust count is 134, comprising 122 General Acute and 12 Specialist trusts. All formula ranges confirmed as $2:$135. | Resolved, row count corrected |
| AQ-018 | Regional summary table, South East | **M** Duplicate South East entry in summary table was inflating total trust count to 141 instead of 122. Identified and removed during validation check. | Resolved, duplicate removed |
| AQ-019 | Regional analysis, all regions | **H** Corrected regional averages show London as best performing region (average Below Average Count of 2.75) and Midlands as worst (4.04 across 23 trusts). Previous analysis was incorrect due to duplicate region error. Final regional breakdown confirmed across 122 General Acute trusts. | Resolved, analysis updated with correct figures |
| AQ-020 | Diagnostics over 6 weeks, all trusts | **H** Highest standard deviation of all seven metrics (0.14) with a 51 percentage point range. Variation may reflect genuine performance differences or inconsistent data collection practices across trusts. Recommend caution when using this metric for direct benchmarking. | Flagged, noted in analysis narrative |
| AQ-021 | Elective 52 weeks, all trusts | **L** Lowest standard deviation (0.01) and smallest range (7.7%). Most consistent metric across all trusts, suggests universally managed standard rather than a point of differentiation between trusts. | Noted, included in analysis findings |
| AQ-022 | Cancer metrics, specialist trusts | **M** Cancer Faster Diagnosis and Cancer 62-day Combined both show 100% maximum values, influenced by specialist cancer trusts. Wide ranges of 60.6% and 66.7% respectively partly attributable to specialist trust inclusion despite General Acute filter. N/R values may have allowed some specialist rows through STDEV calculation. | Flagged, specialist trust influence noted in analysis |

The original spreadsheet is included in this repository as `Audit-Log.xlsx`.
